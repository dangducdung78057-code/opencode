# StageOS 艺演助手 - 实现计划

## 概述

面向中小学舞台演出场景的 AI 智能服装规划平台「艺演助手」官网 + 核心功能页。以高端艺术感视觉呈现（水彩质感、莫兰迪色系、东方美学融合），提供从演出参数输入到 AI 服装推荐、配色方案、视觉预览的完整体验。Web 端，Next.js 15 + shadcn/ui + Tailwind v4 技术栈，接入真实 LLM 与生图 API。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js 15 App Router | 现有项目基础，支持 SSR/API Routes |
| UI 组件 | shadcn/ui + Tailwind v4 | 高度可定制，视觉还原度高 |
| 语言 | TypeScript | 类型安全 |
| 数据校验 | Zod | 表单校验与数据契约 |
| LLM | LLM 技能（豆包/DeepSeek/Kimi） | 服装推荐、规则引擎、文案生成 |
| 图片生成 | Image Generation 技能 | 服装效果图、场景插画生成 |
| 动画 | CSS transition + Framer Motion | 高端微动效、滚动触发动画 |
| 图标 | Lucide Icons | 风格统一、轻量 |

## 功能模块

### 1. 品牌首页
- **Hero 区**：品牌 Logo + Slogan「让每个孩子的舞台，都被认真对待」+ 双主题视觉（民乐/舞蹈意象）+ CTA 按钮
- **核心价值**：3-4 个价值主张（专业 AI 选款、安全尺码覆盖、背景不撞色、一键采购清单）
- **功能展示**：六大能力卡片（智能选款、配色方案、队形规划、2D 预览、3D 试装、采购清单）
- **场景覆盖**：节目类型展示（合唱/舞蹈/器乐/朗诵/主持/礼仪等）
- **使用流程**：三步向导示意（输入信息 → AI 生成方案 → 确认下单）
- **信任区**：安全承诺、隐私保护、匿名化说明
- **CTA 区**：立即开始体验
- **页脚**：品牌信息、联系方式

### 2. 智能选款页（核心功能）
- **向导式输入**：分步表单，降低用户认知负担
  - Step 1: 节目信息（类型、主题、级别、人数）
  - Step 2: 学生信息（学段、男女比例、身高区间、特殊体型备注）
  - Step 3: 舞台环境（场地类型、背景色/大屏、灯光、演出日期）
  - Step 4: 预算与偏好（人均预算、风格偏好、亮片接受度、袖长要求）
- **AI 生成动画**：加载态的品牌化动效
- **方案展示**：
  - 主推荐卡（大图 + 款式描述 + 价格 + 尺码覆盖 + 推荐理由）
  - 备选方案（2-3 款横向对比）
  - 配饰建议（鞋子、头饰、道具）
  - 尺码指南
  - 执行清单（采购 timeline）
  - 自检标签（背景不撞色、尺码覆盖、Plan B 已备等）
- **操作区**：调整参数重新生成、导出方案、收藏

### 3. 配色方案页
- 大屏主题色选择器
- 服装配色推荐（男女款 + 占比公式可视化）
- 背景撞色检测提示
- 灯光修正模拟

### 4. 队形与 2D 预览页
- 队形模板选择（弧形/直线/阶梯/星形等）
- 学生身高排布可视化
- 2D 同身高比例预览图
- 可导出图纸

### 5. 关于/帮助页
- 产品介绍
- 使用指南
- 常见问题
- 隐私与安全

## 实施步骤

### 阶段一：原型设计

1. **原型设计 - 全站高保真原型**
   - 加载 design-canvas 技能，基于首页设计图的视觉语言（水彩质感、莫兰迪色系、东方美学）完成高保真 HTML 原型
   - 关键页面：首页（Hero + 价值主张 + 功能展示 + 场景 + 流程 + CTA）、智能选款页（向导式输入 + 方案展示）
   - 交付后提示用户验收原型，确认后进入开发阶段

### 阶段二：代码开发

2. **项目基础搭建 - 设计系统与基础设施**
   - 安装 Tailwind v4、shadcn/ui、Lucide Icons 等依赖
   - 配置 globals.css（迁移原型 @theme 变量，定义品牌色、字体、圆角、阴影、动效）
   - 配置 layout.tsx（中文字体、主题、SEO 元信息）
   - 整合 stageos-shared 类型与 schema
   - 涉及文件：`src/app/globals.css`、`src/app/layout.tsx`、`src/lib/types.ts`

3. **首页开发 - 品牌形象与视觉冲击**
   - Hero 区：品牌 Logo + Slogan + 双主题视觉背景 + CTA 动效
   - 核心价值区：4 大价值主张图标卡
   - 功能展示区：6 大能力卡（智能选款 / 配色方案 / 队形规划 / 2D 预览 / 3D 试装 / 采购清单）
   - 场景覆盖区：节目类型轮播/网格
   - 使用流程区：三步向导可视化
   - 信任区 + CTA 区 + 页脚
   - 涉及文件：`src/app/page.tsx`、`src/components/home/`

4. **公共组件与布局系统**
   - 顶部导航栏（毛玻璃效果 + 滚动变化 + 响应式）
   - 页脚组件
   - 通用组件：渐变背景、玻璃拟态卡片、按钮变体、动画容器
   - 涉及文件：`src/components/layout/`、`src/components/ui/`

5. **智能选款页 - 核心功能体验**
   - 分步向导表单（4 步：节目/学生/舞台/预算）
   - 卡片式选择器、数字滑块、颜色选择器
   - Zod 表单校验
   - AI 生成加载态（品牌化动效）
   - 方案展示（主推荐卡 + 备选 + 配饰 + 尺码指南 + 执行清单 + 自检标签）
   - 涉及文件：`src/app/costume/page.tsx`、`src/components/costume/`

6. **配色方案页 + 队形预览页 + 关于页**
   - 配色页：背景色选择 + 配色方案卡 + 灯光模拟预览
   - 队形页：队形模板列表 + 2D 预览画布（SVG 实现）
   - 关于页：品牌故事 + FAQ 折叠列表
   - 涉及文件：`src/app/color/page.tsx`、`src/app/formation/page.tsx`、`src/app/about/page.tsx`

7. **AI 服务层与 API 集成**
   - LLM 调用封装：服装推荐、配色建议、自检
   - 生图调用封装：服装效果图
   - API Routes：智能选款、配色方案、队形生成
   - Mock 数据兜底（LLM 不可用时的降级方案）
   - 流式输出实现（打字机效果）
   - 涉及文件：`src/app/api/`、`src/lib/ai/`

8. **代码检查与验证**
   - TypeScript 类型检查、构建验证
   - 全页面路由探活、样式一致性核对
   - 响应式适配验证（桌面/平板/手机）
